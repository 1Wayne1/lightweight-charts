# 开发路线图

## M0：初始化（已完成）

- [x] 从 master 创建功能分支，增加应用/服务 workspace 与开发约定。
- [x] 可构建的 Web 图表入口，明确展示演示行情状态。
- [x] 标签页开关、交易对独立周期、本机恢复和领域测试。
- [x] 同步 API 健康检查、数据库初始结构与 Docker Compose 配置。
- [x] 记录画线序列化、离线同步、冲突处理和原生封装边界。

## M1：本机看盘可用（进行中）

- [x] 接入 Binance USDT 现货 / 永续行情、历史分页和 WebSocket 增量。
- [x] 行情状态、断线重连、限流退避和取消请求测试。
- [x] 接入已有绘图插件，桌面提供八组分层工具菜单与最近使用入口，手机提供常用工具和同一分组目录。
- [x] 绘图对象浮动操作栏、颜色/线型弹层、双击与右键操作、工具属性页签及 UTC 坐标编辑；桌面与手机浏览器布局回归。
- [x] 对象附加文字、斐波那契逐层文字、图上编辑、文字样式与对齐，兼容旧画线存储。
- [x] 时间/价格锚点转换、本机持久化、跨周期恢复、删除墓碑与撤销重做。
- [ ] 在 iPhone Safari 真机完成长按切换、缩放、画线与横屏实测（桌面与手机触控模拟已验证）。

验收：BTC 和 ETH 分别设置周期并画线，切换、关闭重开、刷新后各自恢复；历史补齐与切换周期不改变画线对应的市场时间和价格。

## M2：单人自托管 SQLite 同步与无缝迁移（核心已实现，待容器/多设备实机演练）

- [x] Node 24 内置 `node:sqlite`（WAL 模式）、版本化迁移执行器（`schema_migrations`）与运行时请求校验。
- [x] 单人访问口令鉴权（`SYNC_TOKEN` + Bearer Token 常量时间校验）、单容器托管前端静态页面与 API。
- [x] 交易对偏好、单条画线（含墓碑）及共享设置（指标 / 常用周期 / 画线默认样式）同步，`revision` 乐观并发检查与 `mutationId` 幂等事务。
- [x] IndexedDB 持久化离线队列、断网/服务器关机离线续用、409 冲突提示与 `store_id` 切换保护弹窗。
- [x] SQLite 单文件在线热备份（`VACUUM INTO`）与离线 JSON 快照导出/导入，支持服务器 ↔ 电脑随时迁移。
- [x] 双客户端并发冲突、离线重试、墓碑同步、热备恢复与新库迁移自动化测试。
- [ ] 在实际 Docker 服务器、电脑与 iPhone Safari 上完成 HTTPS 反向代理与关机迁移实机演练。

验收：设备 A 修改周期、指标和画线后，设备 B 拉取可恢复；同时编辑返回 409 不静默丢失；服务器临时关机时离线修改可保留并在恢复后补推；删除的画线不复活；下载单个 `.db` 或导出 JSON 迁移到电脑后可继续运行。

## M3：原生多端交付

- [ ] 初始化 Tauri 2，复用 Web 构建产物。
- [ ] macOS / Windows 构建、签名、更新策略和系统安全存储。

- [ ] 前后台切换、移动网络断线、键盘与安全区体验。

验收：macOS、Windows、iOS 三端连接同一个自托管服务，按交易对恢复周期与画线；平台原生构建与实际设备验证分别记录。
