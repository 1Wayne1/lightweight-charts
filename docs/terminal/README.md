# 多端加密货币看盘工作台

基于本仓库的 Lightweight Charts 和画线插件，构建面向 macOS、Windows、iOS 的个人看盘工具。共享 Web 界面通过 Tauri 2 封装；图表配置、周期和画线以交易对为单位保存，最终通过自托管云端跨设备同步。

## 当前可运行的内容

- TypeScript + Vite Web 骨架，使用本仓库构建的图表库。
- TradingView 风格的全屏深色工作区：顶部标签栏、可配置常用周期与分组下拉周期菜单（覆盖 Binance 现货 / 永续全部 15 个 K 线周期，支持星标收藏到顶部快捷栏并本机持久化）、左侧工具栏、右侧自选列表和交易对详情。
- Binance USDT 现货及 USDⓈ-M USDT 永续真实行情，内置八个常用币种的两类市场，可搜索交易所目录中的更多 USDT 交易对。
- 基于 `trading-signals` 的 TradingView 风格指标下拉面板，区分「常用指标」「全部指标（48 项，覆盖趋势均线、通道波动、动量摆动与成交量）」与「已添加」：MA 与 EMA 各自支持最多 5 条可配置周期、颜色和显隐的均线；支持 BOLL、VWAP、SuperTrend、MACD（右侧价格轴同时显示快慢线与能量柱当前值，并支持自定义快慢线与四态能量柱颜色）、RSI、KDJ、ATR 等主图叠加与独立副图，并支持任意调整 K 线主图与各副图的上下顺序，以及时间范围和专注模式。
- 图表指标信息按行展示名称、参数和随十字线变化的数值；箭头统一展开 / 收起主图与 MACD 等副图信息，收起后显示主图指标数量。悬浮或键盘聚焦显示眼睛和设置按钮，手机直接显示；隐藏曲线仍保留名称与恢复入口。隐藏、收起状态保存到本机，兼容已有指标设置。
- 复用仓库 `@tradingview/lwc-plugin-drawing-tools` 绘图插件：桌面左侧栏按光标、趋势线、江恩与斐波那契、形态、预测与测量、几何与画笔、文字与标注、图标排列。图标统一居中，右侧箭头在悬浮或键盘聚焦时显示。点击主按钮选中该组当前工具，再点展开菜单，再点收起并保留当前工具；选择子工具后替换该组图标与默认工具。箭头可直接展开或收起含子小节的菜单，只展示已实现工具。手机保留独立绘图面板，置顶常用工具并使用同一分组目录。
- 左侧栏提供测量与放大快捷操作，以及磁吸、连续绘图、全局锁定、显隐和删除控制。菜单支持方向键、Enter、Escape 和点击外部关闭；批量锁定与删除可一次撤销，删除保留已锁定画线。画线支持时间与价格锚点本机持久化、按交易对隔离、切换周期/历史补齐重投影、删除墓碑、撤销/重做、刷新恢复与 JSON 备份导出。
- 对应现有线条、形状、通道、范围和箭头标记支持直接附加文字，斐波那契回撤 / 扩展支持各层级文字；提供图上编辑、文字样式和对齐设置，兼容旧数据。详见[附加文字说明与官方依据](drawing-text.md)。
- 绘图属性采用紧凑的可拖动浮动栏，按工具实际能力显示颜色、填充、线宽、线型、字号、锁定、删除和更多操作；颜色点选或拖拽取色器 / 不透明度滑块时实时渲染到图表，无需关闭弹窗即可对比效果。按工具类型本机记住上次修改的颜色、线宽、线型等样式，后续绘制同类型画线自动沿用（不继承锁定、隐藏与实例文字）。点击空白或按 Esc 取消选中后隐藏；双击对象或点击齿轮打开分工具页签设置。斐波那契层级可逐行调整开关、比例和颜色，坐标使用 UTC 时间与价格；确定时整次提交，取消不保存并还原预览，支持一次撤销。桌面顶部、手机图表选项提供撤销 / 重做。
- K 线主图右侧价格轴提供水平线快捷入口：鼠标移入价格轴时显示价格标签、虚线与「＋」，点击直接按该价位画线；手机轻点价格轴后再点「＋」。价格遵循交易对精度，复用本机保存和撤销 / 重做；拖动坐标轴、取消手势及副图坐标轴不会触发画线。
- 独立手机界面：参考 TradingView 的浅色自选表 / 深色图表两页结构，仅保留这两个底部导航入口；横竖屏均采用「图表 → 底部操作栏（交易对滚轮、周期、绘图、指标、绘图对象、更多选项、快捷撤销与全屏切换）→ 底部两页导航」层级，全屏时收起底部导航栏以最大化图表面积。图表区域采用 `touch-action: none`、Safari 手势防护与跨面板双指捏合缩放，避免双指缩放 K 线或输入搜索时误缩放整个应用界面。
- 手机左下角交易对短按搜索，按下后直接上下滑动即可即时呼出无限循环的连续 3D 滚轮预选、松手切换；手机端切换交易对（滚轮、自选表或搜索）沿用当前手机端周期并独立本机保存，不影响桌面端按标签页 / 交易对隔离保存的周期。周期、指标与选项弹窗采用平滑上滑与手势跟手拖拽动画。
- 本机保存标签页、周期与画线，刷新或重新打开交易对可恢复设置；损坏数据保留原内容并阻止静默覆盖。
- 历史 K 线分页、实时增量更新、断线重连与缺口补齐；独立领域模型、行情、画线持久化/坐标重投影与手势测试。
- 单服务一体化运行与默认本机 SQLite 存储：开发态 `pnpm dev:terminal` 或生产态 `pnpm start:terminal` 均只需启动一个服务进程，页面启动时自动连接同源本机内置 SQLite 存储（默认 `deploy/terminal/data/terminal.db`），无需单独运行存储服务或配置地址；并保留自定义远程同步服务、IndexedDB 离线队列、409 冲突解决、`store_id` 切换保护、SQLite 单文件热备份（`.db`）与离线 JSON 快照导入导出。
- 独立「设置」页面（桌面右侧栏齿轮 / 状态栏快捷入口；手机自选表右上角齿轮 / 图表 `⋯ → 设置`）：集中管理「数据源」「存储服务」「数据导入导出」。内置 Binance USDT 现货 / 永续公开行情（支持在界面配置自定义镜像 / 代理地址），并支持配置**通用自定义协议源**（标准 HTTP JSON `/klines` + 可选 `/instruments`、`/ticker` 与可选 WebSocket / REST 轮询）；画线与周期严格绑定数据源标识与交易对，切换数据源不影响已有标签与画线。

**行情默认接入 Binance 公开 REST / WebSocket（无需 API Key），并可在设置页自定义代理或切换通用自定义协议源；画线、指标与周期默认自动保存到一体化本机 SQLite，并支持切换至自托管远程同步服务；币本位、交割合约、原生安装包以及 iPhone Safari / Docker 生产环境实机演练仍待完成。** 页面会明确区分本机存储、远程同步与离线浏览器缓存状态。

## 快速开始

沿用仓库的 Node.js >= 22.3 和 `package.json` 中固定的 pnpm 版本。

```bash
pnpm install --frozen-lockfile
# 首次运行先构建图表库、绘图插件和应用
pnpm build:terminal
# 开发模式（单命令同时启动前端热更新 + 内置本机 SQLite 存储）
pnpm dev:terminal
# 或本机单进程运行已构建产物 + 内置 SQLite 存储（http://127.0.0.1:8080）
pnpm start:terminal
```

打开 <http://127.0.0.1:5173>（或 `pnpm start:terminal` 的 <http://127.0.0.1:8080>），将自动连接本机内置 SQLite 存储（`deploy/terminal/data/terminal.db`）。两个默认标签页分别保存周期；打开已存在的交易对会聚焦该标签页。关闭标签页会保留交易对设置；关闭全部标签页后可以重新打开。

桌面顶部标签可左右拖动排序，相邻标签会平滑让位，松手后滑入新位置并保存，刷新后恢复；标签较多时拖到左右边缘会自动滚动。按 Esc 或拖出标签栏松手可取消并回到原位。键盘聚焦标签后可用 Alt + 左右方向键移动位置。排序保留当前活动图表、缩放与绘图状态，并遵循系统的减少动态效果设置。

手机上点选自选表中的交易对可进入图表；按住左下角交易对约 320ms 后，上下滑动切换预选项，松手才应用。手势取消、页面退到后台或屏幕旋转会取消预选。也支持键盘：交易对按钮上按空格 / Enter 打开浮窗，上下键预选，Enter 确认，Escape 取消。周期面板顶部手柄可拖动或点击展开。

手机与桌面复用同一套交易对偏好：切换交易对恢复各自周期，旋转屏幕不会修改周期。当前已在浏览器中检查手机竖屏 / 横屏布局，iOS 真机和原生封装仍待验证。

```bash
pnpm typecheck:terminal
pnpm test:terminal
pnpm lint:terminal
pnpm build:terminal
# 本机一体化单进程启动（托管 dist + 本机 SQLite，默认 http://127.0.0.1:8080）
pnpm start:terminal
# 可选：单独运行带口令保护的同步服务（读取 deploy/terminal/.env）
pnpm dev:sync
```

工具栏浏览器回归可在启动 `pnpm dev:terminal` 后运行 `pnpm --filter @terminal/web test:toolbar`；测试使用独立无头浏览器和固定行情响应，覆盖菜单分组、绘图、锁定、删除撤销、刷新恢复、价格轴快捷水平线及桌面 / 手机横竖屏。可通过 `TERMINAL_TEST_URL` 指定本机服务地址，通过 `TERMINAL_SCREENSHOTS` 指定截图输出目录；固定测试行情不会进入正常应用。

生产 Web 构建输出到 `apps/terminal-web/dist/`；使用 `pnpm start:terminal` 或 Docker 单容器运行时会自动托管该静态产物并启用同源 SQLite 存储。

## 行情数据源配置（服务中继、Binance 与通用自定义协议）

- 在独立**「设置 → 数据源」**页面可随时查看支持的数据源类型、测试连接并切换默认数据源：
  1. **Binance（内置默认）**：支持 USDT 现货与 USDⓈ-M USDT 永续，提供两种行情获取方式（均沿用 `binance` 交易对身份，原有画线完全复用）：
     - **通过当前服务转发（默认推荐）**：K 线 REST、交易对目录（服务端内存缓存 10 分钟）与实时 WebSocket 流均通过当前连接的电脑 / 服务器 `/v1/market/binance/*` 中继发出，手机访问电脑或服务器链接时无需单独开代理；若未填写口令或服务不可达会明确提示，不静默切回浏览器直连。电脑端可通过 `MARKET_PROXY_URL=http://127.0.0.1:7890` 让服务端复用本机代理。
     - **浏览器直连 Binance**：由当前设备浏览器直连 Binance，并支持在设置页覆盖 4 个公开 REST / WebSocket 代理或镜像地址并一键恢复官方默认。
  2. **通用自定义协议源（HTTP JSON + 可选 WebSocket）**：支持接入自建行情网关或本地 K 线服务，仅需实现标准 `/klines` 接口（`/instruments`、`/ticker` 与 WebSocket 均可选；留空 WebSocket 时自动按设定间隔 REST 轮询，并明确标注为轮询状态）。
- 画线、周期与数据源标识（`venue`）、市场类型及交易对强绑定（如 `binance:spot:BTC-USDT` 与 `custom:spot:BTC-USDT` 相互独立）。切换默认数据源后，已打开的旧数据源标签页与画线保持不变，且按 `venue` 路由各自的行情源，仅新搜索和打开的交易对使用新数据源。

- 搜索面板可切换「全部 / 现货 / USDT 永续」；例如 `BTCUSDT` 是现货，`BTCUSDT.P` 是 USDT 永续。两者周期和未来画线分别保存。
- 首次读取最近 500 根 K 线，向右拖动图表以查看更早时间、接近历史左边界时自动补取 500 根。时间范围按钮作用于当前已加载数据。
- K 线及真实基础币成交量通过 WebSocket 增量更新；24 小时报价来自 ticker 的滚动统计，不按当前图表周期计算。
- 实时连接中断会显示重连状态；重新连接后用 REST 补齐缺口，再恢复增量更新。请求超时和限流会退避重试。关闭或切换交易对、页面退出时会取消旧请求与订阅。
- 已有演示工作区读取时迁移到 Binance 现货，保留原偏好备份；已存在的 Binance 偏好优先，不覆盖永续设置。

默认直连以下公开地址，不需要运行同步 API：

| 市场 | REST | WebSocket |
| --- | --- | --- |
| 现货 | `https://data-api.binance.vision/api/v3` | `wss://data-stream.binance.vision/stream` |
| USDT 永续 | `https://fapi.binance.com/fapi/v1` | `wss://fstream.binance.com/market/stream` |

需要自托管行情转发时，可参考 `apps/terminal-web/.env.example` 设置四个 `VITE_BINANCE_*` 地址后重启开发服务 / 重新构建。REST 配置为根地址（应用追加 `/api/v3` 或 `/fapi/v1`），WebSocket 配置保留合约 `/market` 路径（应用追加 `/stream`）。转发服务需要支持浏览器 CORS 和 WebSocket。这些配置是公开地址，不放 API Key。当前网络或地区无法访问 Binance 时会明确显示错误，不使用模拟数据冒充行情。

已在本机浏览器实测现货、永续的历史 K 线 / ticker / 实时 K 线，并验证搜索目录及周期隔离；iOS 真机仍待验证。协议参考 [现货官方文档](https://github.com/binance/binance-spot-api-docs) 和 [合约官方 SDK market 模块](https://github.com/binance/binance-connector-js/blob/master/clients/derivatives-trading-usds-futures/src/websocket-streams/modules/market-api.ts)。
